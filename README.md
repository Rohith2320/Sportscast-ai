# SportsCast AI

Multi-agent sports analysis pipeline — NBA, F1, Soccer, Valorant, MLB.

## MCP Server

SportsCast AI exposes an MCP server for AI agent integration.

Start: `python mcp_server.py` (runs on port 8001)

Tools: `analyze_sport`, `list_cached_analyses`, `chat_about_game`, `discover_latest_game`

Connect Claude Desktop or any MCP client to `http://localhost:8001`
